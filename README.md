# Rose App Design System

Team 8 design system foundation for the Rose App project.

## Included

- Color tokens for light and dark mode
- Typography tokens using Sarabun and Tajawal
- Theme preview components
- Basic usage examples for Tailwind classes

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the design system preview.

## Checks

```bash
npm run lint
npm run build
```
